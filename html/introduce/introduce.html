일하는 방식 및 가치관

01

화면에 머물지 않고 서비스의 본질을 고민합니다

단순한 제작자가 아닌 '서비스의 주인'으로 일합니다. 디자인·퍼블리싱·운영을 두루 거치며 화면 뒤의 흐름까지 이해하는 기본기를 쌓았고, 새로운 도구를 영리하게 활용해 작업 효율을 높입니다.

02

사용자와 관리자, 모두를 위한 UX

서비스를 이용하는 유저뿐만 아니라 시스템을 운영하는 관리자의 경험까지 고려합니다. 복잡한 로직을 가장 단순하고 직관적인 UI로 풀어냈을 때 비즈니스의 진짜 가치가 창출된다고 믿습니다.

사용성 개선 사례

콘도 예약 시스템 — 원하는 정보를 빠르게 찾는 메뉴 구조

관리자가 여러 콘도 정보를 반복해서 조회하는 과정을 관찰하고, 메뉴의 정보 구조와 선택 상태를 명확하게 개선한 경험.

  1. 상황

    관리자는 여러 콘도의 예약 현황을 오가며 확인해야 했지만, 기존 화면에서는 전체 목록과 현재 선택한 콘도를 빠르게 구분하기 어려워 반복 업무 중 탐색 부담이 컸습니다.

  2. 진단

    실제 업무 흐름을 기준으로 필요한 정보의 우선순위를 나누고, 메뉴명·간격·선택 상태·목록 이동 과정에서 사용자가 놓치는 지점을 확인했습니다.

  3. 해결

    목록의 시각적 위계를 정리하고 활성 메뉴를 색상과 배경으로 명확히 구분했습니다. 화면이 좁아져도 정보가 무너지지 않도록 영역 크기와 텍스트 표시 방식도 함께 조정했습니다.

  4. 의미

    기능을 그대로 나열하는 것보다 사용자의 반복 동선을 이해하고 시각적 우선순위를 설계하는 것이 중요했습니다. 작은 UI 차이가 관리 업무의 속도와 정확성을 높일 수 있음을 확인한 경험입니다.
